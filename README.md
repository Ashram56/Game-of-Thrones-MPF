# Game-of-Thrones-MPF

MPF + Godot (GMC) recreation of Stern Game of Thrones LE/Premium 1.37.0 (Spike 1), following Agent C of
[Stern-SAM-Decryption](https://github.com/Ashram56/Stern-SAM-Decryption) (Tron Legacy MPF is the worked example).
Early build: playable-core scope, see [docs/status.md](docs/status.md).

**Verification differs from Tron: there is no PinMAME and no reference trace for Spike 1.** Rules are checked
against the spec (Game-of-Thrones `docs/03-rules.md`, `data/*.csv`) and by code reading only; MPF could not be
installed where this was built, so nothing has run in MPF yet. Every rule carries its confidence
(H table/constant, M constants plus names, L inferred, CFG not recovered, placeholder) in `game/config/rules.yaml`.

## Layout
- `game/config/rules.yaml` - all rule values with confidence; edit this, not the generated modes.
- `game/config/{config,devices,hw_virtual}.yaml` - machine, devices (trough, flippers, tilt, ball save, extra ball).
- `game/config/rom/`, `game/modes/<house or multiball>/` - GENERATED by `scripts/gen_config.py` from the
  extraction data (Game-of-Thrones `data/`, env `GOT_DATA`) and `rules.yaml`. Committed (names and numbers only).
- `game/got/` - `rules_core.py` (pure Python, tested), `award_mode.py` / `base.py` (MPF glue, unverified).
- Media is copyrighted and never committed: `python scripts/gen_media.py --assets /mnt/project-files/got/assets`
  copies the core sounds and DMD frames (128x32) into the gitignored `game/sounds/` and `game/images/`.

## Run and test
- `python tests/run_without_pytest.py` (or `pytest -q tests`): YAML structure, references, generated files current,
  rules vs CSV, rules core.
- With MPF 0.80 installed: `cd game && mpf game . -c config,hw_virtual` (untested).
