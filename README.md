# Game-of-Thrones-MPF

MPF 0.80.1 + Godot 4.5 (mpf-gmc 1.0.0) recreation of Stern Game of Thrones LE/Premium 1.37.0 (Spike 1), following the agents of
[Stern-SAM-Decryption](https://github.com/Ashram56/Stern-SAM-Decryption). The whole game runs in MPF (headless tests, 79 passing) and on
screen under Godot; status and open work: [docs/status.md](docs/status.md).

There is no PinMAME and no reference trace for Spike 1: rules follow the rules thread's extraction in
[Game-of-Thrones](https://github.com/Ashram56/Game-of-Thrones) (`docs/`, `data/*.csv`); the ROM wins over the VPX table. Each rule
carries its confidence (H table, M constants plus names, L inferred, CFG not recovered) in `game/config/rules.yaml`.

## Install and run
```
python3 scripts/setup.py          # venv .venv (mpf==0.80.1), generated config, media, mpf-gmc add-on (+ patch); --dry-run to preview
export GODOT=/path/to/godot       # or tools/godot, or on PATH
python3 scripts/run.py            # Godot, then MPF on virtual hardware; --monitor, --no-godot, --check
```
Media is copyrighted and never committed: `setup.py` takes the ROM-derived assets from `--assets DIR` or `GOT_ASSETS` (sounds, DMD
frames) and skips them with a warning if absent. `run.py --check` verifies that everything the game needs is present and that every
module imports; it generates nothing.

## Layout
- `game/config/rules.yaml` rule values; `game/config/rom/`, `game/modes/<mode>/` GENERATED by `scripts/gen_config.py` (committed, names and numbers only).
- `game/got/` MPF glue (base game, houses, multiballs, combos, mystery, video mode, casual, audits); `game/slides/` Godot slides.
- `bundle_spec.json`, `mpf-package.json`: the platform's game-bundle contract ([docs/bundle.md](docs/bundle.md)). No image is built here.

## Test
`pytest -q tests` (MPF game tests, display smoke tests need Xvfb, package contract tests).
